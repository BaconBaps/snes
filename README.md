# Bedroom Arcade

A Godot 4 interface prototype for a Super Nintendo emulator, set in a 1990s bedroom.

Download and extract the repository. In the Godot Project Manager, choose **Import**, open `project.godot`, then press **F5**.

- Drag a cartridge from the desk to the console slot.
- Click **Power** to turn on the CRT preview.
- Click **Eject**, then drag the cartridge back to the desk.
- Use **F11** to toggle fullscreen.
- Choose a ROM folder to create labels from its `.sfc` and `.smc` filenames. Scroll over the desk for more cartridges.

The CRT displays placeholder artwork. SNES gameplay and online label artwork are planned.
